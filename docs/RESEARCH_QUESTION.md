# 柔性材料角点抓取：研究问题、假设与贡献边界

## 1. 研究现象

历史测试中，ACT 能对毛巾整体平移产生一定同方向动作响应，但双臂仍难以同时抓住两个角。这提示粗粒度视觉条件控制与接触级精确控制之间可能存在性能断层，但该 approach-only 现象不再是新实验的前置任务。

当前证据不足以断定断层来自视觉表示、动作分块、控制时延、双臂协调、夹爪接触，还是示教动作本身的时序多模态。

截至 2026-09-01，新增两个重要现象：

1. E1/E2/E3 在 `M=20` 下分别为 3/10、6/10、8/10，但 E3 换两个未训练相机各为 0/5，旧 Mix-1-300@20k 在三个视角分别为 1/10、0/10、0/9；多视角是否真正有帮助仍由 Mix-1-100@20k、Mix-1-300@60k、All-3@20k 三组收尾实验决定。
2. 100 条成功示教中左先 57 条、右先 43 条，左右首次闭合间隔中位数 2.80 s，且没有一条在 1 s 内完成双侧首次闭合。这提示相似初始视觉状态可能对应两种不同的动作顺序，造成 behavior cloning 的时序多模态与部署时条件分布失配。

## 2. 主研究问题

当前研究按两个有门控关系的层次推进。

### 2.1 当前收尾问题：多视角是否真的解决空间精度

> 在接触精度敏感的柔性材料角点抓取中，多视角数据扩展能否帮助策略将感知与控制误差压入夹爪的物理捕获容差？这种收益来自视角多样性、更多视角曝光还是推理期遮挡与空间互补？

多视角子问题按顺序定义为：

> 同一批 100 条五路同步直接抓角示教中，Mix-1-100@20k 的等样本/等 updates 视角混训、Mix-1-300@60k 的完整三视角覆盖，以及 All-3@20k 的同时多相机输入，是否分别比专用单视角模型学习到更稳定的抓角表示；若有增益，它来自训练视角多样性、更多视角曝光还是推理期遮挡与空间互补？

主要证据链：

```text
多视角条件 → 角点误差/不确定度 → 捕获区域命中 → 稳定抓角成功
```

### 2.2 多视角无可靠增益后的候选主问题：示教时序一致性

> 在双臂柔性材料精细操作中，如果相似初态对应“左先/右先”两种长间隔抓取顺序，行为克隆是否会因为动作标签的时序多模态而产生折中轨迹、错误阶段动作和失败后的分布外传播？固定唯一顺序能否改善可学习性，显式 phase 表征又能否在保留 mixed-order demonstrations 的同时恢复性能？

对应证据链：

```text
Mixed-order demonstrations
        ↓
相似 observation 对应不同 action phase/order
        ↓
动作多模态 / state aliasing
        ↓
第一侧失败后进入训练外条件状态
        ↓
第二侧继续错误阶段动作
        ↓
Fixed-order 是否改善？
        ↓ yes
Phase-ACT 是否能在 mixed-order 数据上恢复？
```

完整实验协议见 [`TEMPORAL_CONSISTENCY_PHASE_ACT_PLAN.md`](./TEMPORAL_CONSISTENCY_PHASE_ACT_PLAN.md)。

## 3. 可证伪假设

| 假设 | 预测 | 反驳条件 |
|---|---|---|
| H1 空间表征 | Marker、局部高分辨率或 Oracle corner 显著降低误差 | Oracle corner 不能改善误差或进入捕获区域比例 |
| H2 时间反馈 | 越晚扰动越难响应；提高反馈频率后改善 | 各阶段都快速响应且 `rho < 1`，但仍抓取失败 |
| H3 接触夹持 | 闭合前已进入捕获区域，但夹空或滑脱占主要失败 | 多数试验闭合前未进入捕获区域 |
| H4 双臂耦合 | 单臂可靠，双臂同时执行时显著退化 | 单臂与双臂条件误差和成功率无明显差异 |
| H5 视角混合现象 | Mix-1-100@20k 优于单视角@20k，或 Mix-1-300@60k 优于 Single-repeat@60k | 两个匹配比较均不改善，或改善只来自无法排除的额外训练曝光 |
| H6 多视角机制 | 收益随深度误差、遮挡或视角偏移的受控变化而变化 | 中间角点指标不变，或收益只来自额外 token/参数 |
| H7 材料点一致性 | 在相同角点监督下，跨视角 loss 进一步改善误差与抓取 | 仅特征相似度改善，或 M3 不优于 M2 |
| H8 单视角压缩 | 可见条件下学生保留部分教师角点与任务收益 | 可见条件仍无改善，或只在不可观测条件声称成功 |
| H9 示教时序一致性 | Fixed-order 相比 Mixed-order 降低闭合误差、动作时序方差，并提高第一/第二侧条件成功率 | A1/A2 与 A0 在多个布局和机制指标上均无一致改善 |
| H10 Phase 表征 | Oracle-Phase ACT 优于 Raw-ACT，Predicted-Phase ACT 能保留大部分收益 | Oracle phase 本身无收益，或收益只存在于离线 phase 分类而不反映真机行为 |

## 5. 候选贡献

只有得到机制证据后，才考虑形成论文贡献。当前有两条互斥优先级不同的候选路线。

### 路线 M：多视角确有机制收益

1. 同源多视角数据扩展对柔性材料角点抓取的受控现象证据；
2. 将角点误差、不确定度、物理捕获区域和稳定抓角成功率连接起来的机制评估；
3. 多视角知识在单外部相机部署中的可保留范围与不可观测边界。

### 路线 T：多视角收益弱，时序一致性成为主瓶颈

1. 真实双臂柔性操作中 demonstration order multimodality 对行为克隆性能的受控证据；
2. 将第一侧抓取、第二侧条件成功和失败传播拆开的机制评估，而不是只报告最终成功率；
3. Phase-ACT：验证显式动作阶段变量能否缓解 mixed-order demonstrations 的 state aliasing；
4. 如果未来加入 corrective demonstrations，再研究 recovery phase，而不是把恢复能力与 phase 表征混在首轮实验中。

两条路线共享的贡献可以是：包含配对布局、动作时序、双臂误差和失败标签的真实机器人实验协议与数据。

## 6. 创新边界

单独换相机、堆叠多相机、直接令同点特征做 L2 相等、增加 Marker、缩短 `chunk_size`、增加普通 corner head、增加 wrist camera/触觉或只在一块毛巾上提高成功率，都不足以构成强研究贡献。

同样，单纯把“左先数据删掉一半”或给网络增加一个 phase embedding 也不自动构成贡献。时序路线必须证明：

- mixed-order 确实造成可复现的性能/机制退化；
- fixed-order 的改善不能简单归因于数据更容易或训练预算差异；
- phase 信息在 Oracle 条件下有因果价值；
- 可部署的 predicted phase 能保留真实机器人收益。

## 7. Kill Criteria

- 直接抓角基线在固定场景不能学习：暂停科研结论，先修复 demonstration、pipeline 或执行链路；
- Oracle controller 不能稳定抓取：先解决硬件、标定和夹爪容差；
- Oracle corner 不改善 ACT：停止将角点检测作为主要路线；
- late perturbation 已稳定收缩误差：停止把固定 chunk 当作主要解释；
- 方法只改善固定布局：不得宣称可变形物体泛化；
- Mix-1-100@20k 与 Mix-1-300@60k 均不优于匹配单视角基线：停止继续扩大视角混训；
- All-3@20k 仍不优于最佳单视角或失败机制不变：停止 Random-2、跨视角 loss 和蒸馏主线，转入 Experiment A；
- A1/A2 Fixed-order 与 A0 Mixed-order 在多个布局和机制指标上基本一致：停止 Phase-ACT，不把“时序多模态”包装成主瓶颈；
- Fixed-order 只在某个布局提高，或差异明显来自数据难度：补数据控制，不进入网络改造；
- C1 Oracle-Phase 不优于 C0 Raw-ACT：停止 Phase-ACT；
- C1 有效但 C2 Predicted-Phase 无法复现：把问题改写为 phase/contact state estimation，而不是继续堆 ACT 参数；
- 在没有 corrective/recovery demonstrations 时，不声称模型具备 failure recovery，也不提前加入 `recovery` phase。
