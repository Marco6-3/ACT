# 课程式 ACT 毛巾折叠：研究问题与最终回答

状态：本阶段已于 2026-09-03 收尾。完整报告见 [../results/final_curriculum_evaluation_2026-09-03.md](../results/final_curriculum_evaluation_2026-09-03.md)。

## 主研究问题

> 对双臂毛巾折叠，先用蓝色方巾直接抓角示教训练基础策略，再在基础策略的困难状态上收集 101 条人工接管完整任务数据并继承微调，是否比基础策略或同 HIL 数据从零训练更可靠，并能处理不同训练暴露与形状条件的毛巾？

这里的“课程”由能力和数据分布递进形成，而不是人为划分的静态标签：

```text
蓝色方巾直接抓角成功示教
  → 基础策略学会接近与部分抓取
  → 部署暴露偏位、夹空等困难状态
  → 人工在困难状态接管并完成全任务
  → 从基础策略继承微调
  → 自主完成抓取到折叠
```

## 已完成的冻结比较

- `base20k`：100 条蓝色正方形毛巾直接抓角数据，训练 20k steps；
- `scratch20k`：随机初始化，在 HIL-101 上训练 20k steps；
- `finetune10k`：从 `base20k` 初始化，在同一 HIL-101 上微调 10k steps；
- 评估：五条实体毛巾随机摆放，每个模型 × 毛巾条件 10 次，合计 150 次；位置坐标、朝向和编码位 ↔ trial ID 映射未入库；
- 汇总结果：`base20k` 13/50、`scratch20k` 10/50、`finetune10k` 35/50。

红、绿方巾是 HIL 内分布，蓝色方巾是预训练内分布；黄色方巾未见但保持正方形；白色同时改变颜色、实例和形状。它们不能被笼统标为“所有模型都见过/都没见过”。

## 假设与结果

| 假设 | 结果 | 证据与边界 |
|---|---|---|
| H1：课程继承有效 | 支持 | `finetune10k` 为 35/50（70%），高于 `base20k` 的 13/50（26%），五个条件的成功数均更高。 |
| H2：HIL 带来整任务能力 | 任务级支持，机制未分离 | 组合路线显著提高完整任务成功；但 HIL 同时带来困难状态数据和任务后半段标签，无法分离两者贡献。 |
| H3：预训练初始化有价值 | 支持训练路线优势，不能单独分离初始化 | `finetune10k` 以 10k HIL updates 达到 70%，高于 HIL-101 从零训练 20k steps 的 `scratch20k`（20%）。这强力支持预训练 + HIL 的实用组合；由于初始化与更新次数同时不同，不能把全部差异单独归因于初始化。 |
| H4：未见方巾泛化 | 初步支持 | 黄色正方形为 6/10；仅一个实例、10 次重复，不能写成已解决颜色泛化。 |
| H5：综合色/形状分布外泛化 | 初步支持但较弱 | 白色长方形为 4/10；它同时改变颜色、实例和形状，不能单独归因于形状。 |

## 最强可声称结论

> 在当前双臂 ACT 毛巾折叠系统和本轮 150 次随机摆放评估下，以蓝色方巾直接抓角为先修能力、再对 rollout 的困难状态进行人工接管完整任务采集并继承微调，形成了比基础策略和同 HIL 数据从零训练更可靠的课程式训练流程；它对未见方巾及综合色/形状分布外条件显示了初步而非普遍的泛化能力。

## 明确不能声称的内容

- 课程学习在所有机器人、数据集、毛巾和布局上普遍优于端到端训练；
- 对白色长方形的差异只由形状造成；
- 已量化对位置偏移幅度、褶皱、材质、照明、新相机或不同控制参数的鲁棒性；
- 已获得跨 seed、跨实例、跨硬件的统计结论。

本次只保存了条件级 0/1 成功编码，缺少可回溯的 TS 编号、视频、阶段标签、时间、折叠误差以及毛巾位置/朝向。该限制不影响已报告的条件成功率，但限制了失败机制分析、位置平衡检查与后续的严格复核。

多视角扩展、示教时序消融和 Phase-ACT 仍有研究价值，但它们不再属于本阶段未完成事项；如重新开展，应作为新的、独立的研究问题。
