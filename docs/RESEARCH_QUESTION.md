# 多视角柔性材料角点抓取：研究问题、假设与贡献边界

## 1. 研究现象

历史测试中，ACT 能对毛巾整体平移产生一定同方向动作响应，但双臂仍难以同时抓住两个角。这提示粗粒度视觉条件控制与接触级精确控制之间可能存在性能断层，但该 approach-only 现象不再是新实验的前置任务。

当前证据不足以断定断层来自视觉表示、动作分块、控制时延、双臂协调或夹爪接触。

## 2. 主研究问题

> 在接触精度敏感的柔性材料角点抓取中，多视角数据扩展如何帮助策略将感知与控制误差压入夹爪的物理捕获容差？这种收益来自视角多样性、深度、遮挡互补还是视角偏差抑制？能否通过跨视角材料点表示与知识迁移，将收益保留到单外部相机部署？

多视角子问题按顺序定义为：

> 同一批 100 条五路同步直接抓角示教中，Mix-1-100@20k 的等样本/等 updates 视角混训、Mix-1-300@60k 的完整三视角覆盖，以及 All-3@20k 的同时多相机输入，是否分别比专用单视角模型学习到更稳定的抓角表示；若有增益，它来自训练视角多样性、更多视角曝光还是推理期遮挡与空间互补？

主要证据链必须同时跨越感知与物理结果：

```text
多视角条件 → 角点误差/不确定度 → 捕获区域命中 → 稳定抓角成功 → 单视角保留率
```

## 3. 可证伪假设

| 假设 | 预测 | 反驳条件 |
|---|---|---|
| H1 空间表征 | Marker、局部高分辨率或 Oracle corner 显著降低误差 | Oracle corner 不能改善误差或进入捕获区域比例 |
| H2 时间反馈 | 越晚扰动越难响应；提高反馈频率后改善 | 各阶段都快速响应且 `rho < 1`，但仍抓取失败 |
| H3 接触夹持 | 闭合前已进入捕获区域，但夹空或滑脱占主要失败 | 多数试验闭合前未进入捕获区域 |
| H4 双臂耦合 | 单臂可靠，双臂同时执行时显著退化 | 单臂与双臂条件误差和成功率无明显差异 |
| H5 视角混合现象 | Mix-1-100@20k 优于单视角@20k，或 Mix-1-300@60k 优于 Single-repeat@60k | 两个匹配比较均不改善，或改善只来自无法排除的额外训练曝光 |
| H6 多视角机制 | 收益随深度误差、遮挡或视角偏移的受控变化而变化 | 中间角点指标不变，或收益只来自额外 token/参数 |
| H7 材料点一致性 | 在相同角点监督下，跨视角 loss 进一步改善误差与抓取 | 仅特征相似度改善，或 M3 不优于 M2 |
| H8 单视角压缩 | 可见条件下学生保留部分教师角点与任务收益 | 可见条件仍无改善，或只在不可观测条件声称成功 |

## 4. 最小区分实验

| 对照 | 主要隔离因素 |
|---|---|
| Raw RGB + ACT | 当前整体系统 |
| Marker + ACT | 视觉显著性 |
| Oracle corner + ACT | 角点感知 |
| Oracle corner + 笛卡尔控制器 | 策略动作生成与执行 |
| 单臂与双臂配对实验 | 双臂耦合 |
| 50/30/15 mm late perturbation | 接触前反馈带宽 |
| E1 / E2 / E3 | 三个外部方位的专用单视角能力 |
| Mix-1-100@20k / 单视角@20k | 固定样本数和 updates 下的训练视角多样性 |
| Mix-1-100@20k / Mix-1-300@60k / Single-repeat | 完整视角覆盖与额外训练曝光 |
| Mix-1 / All-3 | 训练视角混合与推理期同时多视角互补 |
| M2 角点监督 / M3 跨视角一致性 | 一致性 loss 的增量贡献 |
| 多视角教师 / 单视角学生，按可见性分层 | 表征可压缩性与不可观测上限 |

## 5. 候选贡献

只有得到机制证据后，才考虑：

1. 同源多视角数据扩展对柔性材料角点抓取的受控现象证据；
2. 将角点误差、不确定度、物理捕获区域和稳定抓角成功率连接起来的机制评估；
3. 跨视角材料角点一致性对物理抓取误差的增量作用；
4. 多视角知识在单外部相机部署中的可保留范围与不可观测边界；
5. 包含配对布局、相机干预、双臂误差和失败标签的真实机器人协议与数据。

## 6. 创新边界

单独换相机、堆叠多相机、直接令同点特征做 L2 相等、增加 Marker、缩短 `chunk_size`、增加普通 corner head、增加 wrist camera/触觉或只在一块毛巾上提高成功率，都不足以构成强研究贡献。跨视角对应在刚体和非刚体视觉表示中均已有先例；本项目的贡献必须落在接触关键型柔性操作的机制证据、物理误差和可压缩边界上。

## 7. Kill Criteria

- 直接抓角基线在固定场景不能学习：暂停科研结论，先修复 demonstration、pipeline 或执行链路；
- Oracle controller 不能稳定抓取：先解决硬件、标定和夹爪容差；
- Oracle corner 不改善 ACT：停止将角点检测作为主要路线；
- late perturbation 已稳定收缩误差：停止把固定 chunk 当作主要解释；
- 方法只改善固定布局：不得宣称可变形物体泛化。
- Mix-1-100@20k 与 Mix-1-300@60k 均不优于匹配单视角基线：停止继续扩大视角混训；
- All-3@20k 仍不优于最佳单视角或失败机制不变：停止 Random-2、跨视角 loss 和蒸馏主线，转向示教、反馈、接触与控制方法；
- M3 不优于具有相同角点监督的 M2：停止将一致性 loss 作为贡献；
- 多视角优势只出现在部署视角完全不可见时：不得宣称可无损压缩到单视角。
