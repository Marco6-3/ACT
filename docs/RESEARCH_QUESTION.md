# 研究问题、假设与贡献边界

## 1. 研究现象

ACT 能对毛巾整体平移产生一定同方向动作响应，但双臂仍难以同时抓住两个角。这提示粗粒度视觉条件控制与接触级精确控制之间可能存在性能断层。

当前证据不足以断定断层来自视觉表示、动作分块、控制时延、双臂协调或夹爪接触。

## 2. 主研究问题

> 在可变形物体关键点抓取中，动作分块模仿策略为什么能够响应目标的粗粒度位姿变化，却不能稳定将接触前误差收敛到任务的物理捕获区域？

多视角子问题按顺序定义为：

> 同步外部视角数量是否提高毛巾角点捕获精度；该收益来自深度、遮挡互补、视角偏差抑制还是普通正则化；跨视角材料点一致性是否具有超过角点监督和普通融合的增量价值；这种规范表示在何种可见性条件下能压缩到单外部相机？

## 3. 可证伪假设

| 假设 | 预测 | 反驳条件 |
|---|---|---|
| H1 空间表征 | Marker、局部高分辨率或 Oracle corner 显著降低误差 | Oracle corner 不能改善误差或进入捕获区域比例 |
| H2 时间反馈 | 越晚扰动越难响应；提高反馈频率后改善 | 各阶段都快速响应且 `rho < 1`，但仍抓取失败 |
| H3 接触夹持 | 闭合前已进入捕获区域，但夹空或滑脱占主要失败 | 多数试验闭合前未进入捕获区域 |
| H4 双臂耦合 | 单臂可靠，双臂同时执行时显著退化 | 单臂与双臂条件误差和成功率无明显差异 |
| H5 多视角现象 | V3 比容量匹配 V1 降低闭合误差并提高双角抓取 | 配对差异不达到预设最小有意义效应 |
| H6 多视角机制 | 收益随深度误差、遮挡或视角偏移的受控变化而变化 | 中间角点指标不变，或收益只来自额外 token/参数 |
| H7 材料点一致性 | 在相同角点监督下，跨视角 loss 进一步改善误差与抓取 | 仅特征相似度改善，或 M3 不优于 M2 |
| H8 单视角压缩 | 可见条件下学生保留部分教师角点与任务收益 | 可见条件仍无改善，或只在不可观测条件声称成功 |

## 4. 最小区分实验

| 对照 | 主要隔离因素 |
|---|---|
| Raw RGB + ACT | 当前整体系统 |
| Marker + ACT | 视觉显著性 |
| Oracle corner + ACT | 角点感知 |
| Oracle corner + 笛卡尔控制器 | 策略动作生成与执行 |
| 单臂与双臂配对实验 | 双臂耦合 |
| 50/30/15 mm late perturbation | 接触前反馈带宽 |
| V1 / V2 / V3 + V1-repeat | 外部视角数量与容量混杂 |
| 同时多视角 / Random-1 / Random-subset | 信息融合与视角正则化 |
| M2 角点监督 / M3 跨视角一致性 | 一致性 loss 的增量贡献 |
| 多视角教师 / 单视角学生，按可见性分层 | 表征可压缩性与不可观测上限 |

## 5. 候选贡献

只有得到机制证据后，才考虑：

1. 将粗视觉跟随、接触前误差收缩和物理捕获区域连接起来的评估协议；
2. 动作分块模仿策略在可变形关键点抓取中的失败机制分解；
3. 由物理容差和不确定度触发的粗到细闭环策略；
4. 包含配对扰动、双臂误差和失败标签的真实机器人数据集。
5. 跨视角材料角点一致性对物理捕获误差的作用机制及其单视角可压缩边界。

## 6. 创新边界

单独换相机、堆叠多相机、直接令同点特征做 L2 相等、增加 Marker、缩短 `chunk_size`、增加普通 corner head、增加 wrist camera/触觉或只在一块毛巾上提高成功率，都不足以构成强研究贡献。跨视角对应在刚体和非刚体视觉表示中均已有先例；本项目的贡献必须落在接触关键型柔性操作的机制证据、物理误差和可压缩边界上。

## 7. Kill Criteria

- 固定场景不能过拟合：暂停科研结论，先修复 pipeline；
- Oracle controller 不能稳定抓取：先解决硬件、标定和夹爪容差；
- Oracle corner 不改善 ACT：停止将角点检测作为主要路线；
- late perturbation 已稳定收缩误差：停止把固定 chunk 当作主要解释；
- 方法只改善固定布局：不得宣称可变形物体泛化。
- V3 不优于容量匹配 V1：暂停跨视角 loss 和蒸馏主线；
- M3 不优于具有相同角点监督的 M2：停止将一致性 loss 作为贡献；
- 多视角优势只出现在部署视角完全不可见时：不得宣称可无损压缩到单视角。
