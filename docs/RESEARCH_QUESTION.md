# 课程式 ACT 毛巾折叠：研究问题与结论边界

## 主研究问题

> 对双臂毛巾折叠，先用直接抓角示教训练基础策略，再在基础策略的困难状态上进行人工接管并微调，是否比基础策略或同数据从零训练更可靠、更数据高效，并对颜色/毛巾实例变化具有泛化性？

这里的“课程”不是预先人为划分标签的抽象阶段，而是由能力和数据分布递进形成：

```text
直接抓角成功示教
  → 基础策略学会接近与部分抓取
  → 部署暴露偏位、夹空等困难状态
  → 人工在困难状态接管并完成全任务
  → 继承基础能力微调
  → 自主完成抓取到折叠
```

## 当前已有证据

- C1 基础模型由 100 条直接抓角数据训练 20k steps；
- C2 原始 HIL 目录当前有 101 条轨迹，每条恰有一次人工接管，数据主要覆盖夹爪偏位等薄弱区域；
- C3 微调明确加载 C1 的 20k checkpoint，并在 HIL 数据上训练 10k steps；
- C4 现场测试观察到完整任务成功率较好，且红、绿毛巾均可工作。

颜色、有效 100 条清单、具体测试次数和成功数尚未写入机器可读元数据，因此不能从目录反推出颜色成功率。

## 可证伪假设

| 假设 | 预测 | 反驳条件 |
|---|---|---|
| H1 课程继承有效 | Fine-tune-10k 在困难偏位上优于 Base-20k 和 HIL-Scratch-10k | 配对布局下无稳定优势，或优势只来自测试顺序/环境漂移 |
| H2 困难状态定向采样有效 | Fine-tune 的提升在偏位布局大于中心布局 | 只在中心提高，偏位失败类型和 base 相同 |
| H3 完整任务扩展有效 | Fine-tune 能在不接管条件下完成抓取、抬升和折叠 | 只能抓起，折叠仍依赖人工或固定开环轨迹 |
| H4 颜色泛化 | 已见红/绿均成功，未见颜色或未见实例仍保持可接受性能 | 只对训练中出现的颜色/实例有效 |
| H5 预训练提高数据效率 | 同为 10k HIL updates，Fine-tune 优于 HIL-Scratch-10k | Scratch-10k 相当或更好 |

## 明天可支持的最强结论

若 Fine-tune 在冻结条件下同时满足：

1. 完整任务成功率高于 Base；
2. 偏位条件改善清楚；
3. 优于 HIL-Scratch-10k；
4. 未见颜色或未见毛巾实例仍有成功；

则可以写：

> 在当前双臂毛巾折叠系统中，以直接抓角为先修技能、用策略 rollout 中的困难状态进行人工纠偏并继承微调，形成了有效的课程式训练流程；它提高了困难初态下的完整任务成功率，并表现出跨颜色/实例的初步泛化。

不能直接写“课程学习普遍优于端到端训练”，因为当前仍是单硬件、单相机配置、单 seed 和有限毛巾集合。若只有 Fine-tune 定性成功而对照无足够样本，应写“工程方案有效”，不写“因果优势已证实”。

## 暂停的旧主线

多视角扩展、示教顺序消融和 Phase-ACT 仍有研究价值，但当前任务目标已经通过 HIL 微调定性达成。除非明日定量结果失败或显示明确瓶颈，否则不继续扩展这些路线。
