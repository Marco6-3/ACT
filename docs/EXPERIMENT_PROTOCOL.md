# 实验协议

## 1. 实验单位

一条 trial 从机器人和毛巾进入预定义初始状态开始，到稳定夹持/完成规定阶段、不可恢复失败、超时或安全停止结束。每条 trial 必须有唯一 `trial_id`，并关联数据集、checkpoint、配置、布局和毛巾实例。

当前主任务不是 approach-only，也不是完整折叠。策略必须从初始状态直接完成双角接近、闭合、抬升 10 cm 和保持 3 s。主要成功标签 `stable_corner_grasp_success=1` 要求：左右夹爪均抓住指定材料角、没有明显夹入过多内侧布料，并在保持阶段无滑脱。折叠结果仅作为可选后续字段。

## 2. 必须冻结或记录的变量

- 机器人和夹爪硬件版本；
- 相机内外参和安装位置；
- 图像预处理；
- 控制模式、频率和端到端延迟；
- checkpoint 选择规则；
- 毛巾实例、层数和背景；
- 初始布局编号；
- 安全速度和工作空间限制。
- 外部相机数量、相机 ID、相机组合和腕部相机集合；
- 相机内外参版本、同步方法、时间偏差和重投影误差；
- 每视角分辨率、视觉 token 数、共享/独立编码器和参数量；
- 目标材料角点 ID、每相机可见性和标注来源。

## 3. 配对初始布局

建立中心位置、左右/前后平移、顺/逆时针旋转和轻微褶皱等固定编号布局。所有待比较方法在相同布局上运行，并随机化方法执行顺序。

## 4. 直接抓角示范与捕获区域实验

首轮 100 条行为克隆示范应完整包含“接近 → 闭合 → 抬升 → 保持”。通过质量检查的成功示范进入初始训练集；安全中断、抓错角、夹空和滑脱 episode 应保留来源与失败标签，但不混入首轮成功示范训练集。

1. 建立角点和夹爪局部坐标系；
2. 找到稳定成功的参考抓取；
3. 分别扫描 `x/y/z/yaw` 偏移；
4. 每个条件至少重复 5 次；
5. 闭合后微抬 5–10 mm；
6. 记录是否夹住目标角、是否夹入过多内侧布料以及是否滑脱。

输出成功概率关于偏移的曲线或捕获区域，而不是单个经验阈值。

## 5. 次级机制诊断：视觉跟随与晚期扰动

记录真实角点位移和左右 gripper 目标变化，估计 `G_x/G_y/G_yaw` 及截距。在距离目标约 50、30、15 mm 时施加可重复扰动，并设置无扰动配对对照。

记录扰动时间、动作方向改变时间、响应延迟、扰动前后误差、`rho`、左右臂同步性和是否进入捕获区域。

## 6. Action Chunk 实验

每个条件必须记录 prediction horizon `K`、executed steps per query `M`、policy query frequency、control frequency、temporal ensemble 和端到端延迟。

优先先改变 `M` 验证反馈反应性，再单独改变 `K`。不要同时改变视角、数据量和 chunk 配置。

当前先固定 E3-Orbbec checkpoint 和相机，在 no-hold runtime 下对 M=5/10/30 各做
20 次。三组使用相同布局顺序和 60 s 超时。该比较回答“当前部署系统中哪个 M 最好”，
不直接证明某个 M 是 ACT 的普适最优值。选出 M 后，后续 E1/E2/E3/E4 比较均固定它，
不再重复全套 M。

## 7. 主要终点

主要终点：抬升 10 cm 并保持 3 s 后的 `stable_corner_grasp_success`。

机制终点：左右闭合误差、角点不确定度、左右/双臂进入捕获区域、左右/双角夹持和抬升保持结果。

次级诊断：跟随增益和偏置、响应延迟、误差收缩率、recovery、条件折叠、完整任务成功和任务时间。次级指标不得替代稳定抓角主要终点。

## 8. 统计要求

- 初步诊断每条件至少 20 次；正式关键比较根据功效分析确定样本量；
- 二元结果报告成功率和置信区间；
- 连续误差报告分布、均值/中位数和置信区间；
- 配对布局不能当作独立随机样本重复计数；
- 正式分析可使用以方法、扰动阶段及交互为固定效应，以布局和毛巾实例为随机效应的混合效应模型；
- checkpoint 和超参数选择与最终测试集隔离。
- 同一 episode 的同步视角不得作为独立示教或独立统计样本；
- E1/E2/E3/E4 使用相同 source episodes、动作标签、数据 split 和配对测试布局；
- 同一 source episode 的不同视角不得跨 train/validation/test；
- 报告相机数量和布局/毛巾实例的交互，不能只报告合并平均值；
- 正式比较预先定义最小有意义效应，并基于初步筛查做功效分析。

## 9. 多视角现象协议

最小条件为 E1、E2、E3、E4/Mix-1 和训练步数匹配的 Single-repeat。腕部相机固定；E1/E2/E3 每个使用 100 个样本，E4 将相同 100 个 source episodes 展开为 300 个视角条件样本，但每条样本仍只输入一个外部相机。

所有模型从同一批同步直接抓角示教派生训练输入。当前模型映射为 E1-D435i1、
E2-D435i2、E3-Orbbec。E4 必须平衡三个外部视角，并分别在三个外部视角下测试。
机器人筛查每个主要条件至少 20 次，使用相同布局并随机化方法顺序。主要输出为稳定抓角
成功率；左右闭合误差、双角进入捕获区域比例和左右/双角夹持率作为机制指标。

E4 每条样本只输入一个外部视角，因此属于视角混训。E3 checkpoint 换到 D435i1 或
D435i2 属于跨相机 OOD 测试。二者均不得写成“同时多视角融合”；真正融合要求模型在
同一时刻接收两台或三台外部相机输入并重新训练。

## 10. 多视角机制协议

- 深度：比较不同相机基线，并在所有角点均可见的条件中报告三维或深度方向误差；
- 遮挡：记录逐角逐相机可见性，使用相机 mask、错帧替换和局部遮挡干预；
- 视角偏差：使用平移、旋转、褶皱、轻微相机位姿变化和 held-out view；
- 正则化：比较 E1/E2/E3、Mix-1、Single-repeat、显式 mask 的 Random-2 和 All-3。

attention/gating 只作为描述性记录；相机依赖必须由干预引起的角点误差或成功率变化支持。

## 11. 跨视角一致性协议

使用材料角点身份和可见性 mask 建立同步正样本。必须将“相同角点监督”与“新增跨视角 loss”分开消融，并监测常数表示坍塌、假负样本和标定误差。

最低比较为 M0 单视角、M1 普通多视角、M2 多视角加角点监督、M3 再加跨视角对比一致性、M4 再加重投影一致性。只有跨视角检索、角点误差和真实抓取形成一致改善链条，才支持方法机制主张。

## 12. 单视角压缩协议

教师使用完整多视角，学生只使用部署外部相机和腕部相机。与无蒸馏单视角、Mix-1 和 Random-2 比较，分别消融规范角点表示、三维角点/不确定度和动作蒸馏。

结果按部署相机中的目标角可见、部分遮挡、完全遮挡分层。完全遮挡下的教师优势不能自动解释为可压缩信息。

## 13. 最低证据标准

任何“方法改善了某机制”的结论必须同时包含中间指标、最终指标、竞争解释对照、失败类别以及适用范围说明。
