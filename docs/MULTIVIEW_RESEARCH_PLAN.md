# 多视角柔性材料角点抓取研究路线

## 1. 研究主线

本项目按以下依赖关系推进，而不是一开始同时加入多视角融合、跨视角损失和知识蒸馏：

```text
现象：同一批直接抓角示教的外部视角混合是否提高稳定抓角成功率？
        ↓
扩展：Random-2 和 All-3 是否提供进一步增益？
        ↓
机制：收益来自视角多样性、深度、遮挡互补，还是普通训练步数增加？
        ↓
方法与压缩：材料点一致性是否有效，能否迁移到单外部相机？
```

腕部相机在所有主要条件中保持不变。第一阶段所有模型每个样本均输入一个外部相机和两个腕部相机；只有 Mix-1 达标后，才改变同时输入的外部相机数量。

第一阶段不训练 approach-only 跟随模型，也不要求先通过张开夹爪的接近测试。每条新示范从预定义初始状态直接完成接近、闭合、抬升 10 cm 和保持 3 s。完整折叠暂不属于主要任务。

## 2. 核心概念

多视角的论文价值不只是提高像素定位分数，而是验证它是否把策略误差推入真实夹爪的物理捕获区域 `C`。稳定抓角可用下式连接感知和接触：

```text
P(stable grasp)
= P(e_close in C)
× P(stable lift | e_close in C)
```

同一物理角点 `P` 在不同相机中的像素坐标通常不同：

```text
p_1 != p_2 != p_3
```

需要对齐的是这些投影位置对应的规范表征或三维点：

```text
z_1(p_1) ~= z_2(p_2) ~= z_3(p_3)
```

或：

```text
X_hat_1(p_1) ~= X_hat_2(p_2) ~= X_hat_3(p_3) ~= X
```

这里的 `P` 必须表示材料角点身份，例如 `A/B/C/D`，不能用会随毛巾旋转而改变的“图像左上角/右上角”。

第一阶段只研究目标材料角点。毛巾内部区域可能无纹理、重复或被遮挡，在没有可靠材料坐标或跟踪标注前，不将稠密对应作为近期交付目标。

## 3. 可证伪假设

### H-MV1：视角混合现象

在相同 100 个 source episodes、训练预算和测试布局下，将三个单外部视角展开为 300 个视角条件样本训练 Mix-1，会比专用单视角模型降低闭合时刻角点误差并提高双角抓取成功率。

反驳条件：Mix-1 相对最佳单视角及训练步数控制没有达到预先定义的最小有意义差异，或只在一个外部视角下提升。

### H-MV2：角点状态不确定度机制

多视角收益主要通过降低接触前角点状态不确定度产生，而不是仅提供更多像素。

反驳条件：角点二维/三维误差和不确定度不下降，但任务成功率变化；此时应检查控制、正则化或其他混杂因素。

### H-MV3：跨视角材料点一致性

在具有相同角点监督的容量匹配基线上，跨视角对应损失能够进一步改善角点检索、闭合误差和真实抓取。

反驳条件：只改善特征相似度而不改善角点误差或抓取成功率，或者提升完全来自额外角点标注。

### H-MV4：条件性单视角压缩

当部署相机和腕部相机仍包含足够角点信息时，多视角教师的规范角点表示可以蒸馏到单外部相机学生。

反驳条件：学生在角点清晰可见条件下仍无改善。完全遮挡条件不要求无损压缩，应单独报告其不可观测上限。

## 4. Phase 1：一周现象筛查

### 4.1 数据设计

- 用同一批 100 条直接抓角示教同步保存 `external_1/2/3` 和两个腕部视角；
- 每条示范包含接近、闭合、抬升 10 cm 和保持 3 s；首轮训练只使用通过质量检查的成功示范；
- 先按 source episode 划分 train/val/test，再在每个 split 内展开视角；
- 三个同步外部视角形成 300 个视角条件样本，但仍只有 100 条独立示教；
- E1/E2/E3 和 E4 使用完全相同的 source episode 划分；
- 所有条件使用相同动作、示教数量、checkpoint 选择规则和机器人测试布局。

### 4.2 最小实验矩阵

| 条件 | 每条样本的外部相机输入 | 样本数 | 目的 |
|---|---|---:|---|
| E1 | `external_1` | 100 | 单视角方位 1 |
| E2 | `external_2` | 100 | 单视角方位 2 |
| E3 | `external_3` | 100 | 单视角方位 3 |
| E4 / Mix-1 | `external_1/2/3` 中的一台 | 300 个视角样本 / 100 个 source episodes | 跨视角混合训练 |
| Single-repeat | 最佳单视角重复采样 | 与 E4 相同 updates | 排除训练步数混杂 |
| E5 / Random-2 | 随机两台，固定槽位和 mask | 后续阶段 | 两视角互补 |
| E6 / All-3 | 三台同时 | 后续阶段 | 多视角信息上限 |

E4 的统一外部相机输入 key 在一个完整样本/action chunk 内只对应一个相机，三个相机必须均衡采样。E5 应使用固定外部相机槽位和显式 mask，不用全黑图像作为隐式缺失标记。

### 4.3 本周核心输出

1. 稳定抓角成功率（主要终点）；
2. 左、右角闭合误差；
3. 双角进入物理捕获区域的比例；
4. 左、右及双角夹持率和抬升保持率。

同时保存目标角可见性、失败代码和完整折叠字段（若运行），但不以折叠结果替代抓角主要终点。

自动评估流水线应从 gripper command 定位闭合时刻，导出闭合前后关键帧，写入逐 trial CSV，并生成人工可复核的失败分类。Marker 仅作为快速测量或诊断工具；若使用，应避开真实夹持区并将 marked/unmarked 条件分开，不能让 Marker 改变接触物理或成为策略捷径。

## 5. Phase 2：机制区分

### 5.1 深度/视差

- 比较小基线和大基线相机组合；
- 在所有目标角均可见的样本中单独统计收益；
- 报告 `x/y/z` 分量或可获得的三维角点误差；
- 检查增益是否随相机基线和深度方向误差变化。

### 5.2 遮挡互补

- 为每个目标角记录每个相机的可见、部分遮挡、完全遮挡；
- 在推理时逐个 mask 相机；
- 将单个相机替换成错误时间帧，测量性能变化；
- 分层报告主视角无遮挡和被夹爪/机械臂遮挡时的多视角收益。

### 5.3 视角偏差和数据正则化

- 使用毛巾平移、旋转和轻微褶皱的配对布局；
- 加入轻微相机位姿变化或 held-out 外部视角；
- 比较 E1/E2/E3、Mix-1、Single-repeat、Random-2 和 All-3；
- 如果 Mix-1 已达到部署目标，不优先引入复杂蒸馏。

## 6. Phase 3：跨视角材料点一致性

### 6.1 数据前提

- 相机内外参和时间同步版本化；
- 记录重投影误差，且误差尺度应显著小于夹爪捕获区域；
- 标注目标材料角点在各相机的像素位置与可见性；
- 被完全遮挡的局部点不参与正样本对齐；
- Marker 可以用于测量或诊断，但需要避免改变目标角接触物理，并与无 Marker 测试分开。

### 6.2 模型与损失

优先使用共享视觉编码器、相机位姿/ID、每视角角点热图头、跨视角投影头和 ACT 动作头。

正样本一致性不能单独使用，否则可能产生常数表示。候选损失为：

```text
L = L_ACT + lambda_kp * L_keypoint
          + lambda_cv * L_contrastive
          + lambda_rp * L_reprojection
```

`L_contrastive` 将同一材料角点的跨相机特征作为正样本，将不同材料点作为受控负样本。对称或无纹理角点可能形成假负样本，必须结合材料身份、时序或几何信息处理。

### 6.3 必需消融

| 模型 | 多视角 | 角点监督 | 跨视角损失 | 重投影损失 |
|---|---:|---:|---:|---:|
| M0 | 否 | 否 | 否 | 否 |
| M1 | 是 | 否 | 否 | 否 |
| M2 | 是 | 是 | 否 | 否 |
| M3 | 是 | 是 | 是 | 否 |
| M4 | 是 | 是 | 是 | 是 |

只有 `M3 > M2` 才支持跨视角一致性本身有效。只有特征检索改善而物理抓取不改善，不能支持任务机制主张。

## 7. Phase 4：单视角压缩

只有满足以下条件才启动教师—学生蒸馏：

1. All-3 或跨视角一致性模型在配对实验中可靠优于最佳单视角；
2. 该优势伴随角点误差或不确定度下降；
3. Mix-1 尚未达到目标部署性能。

教师输入 `front + left + right + wrist`，学生输入部署时的 `front + wrist`。优先蒸馏：

1. 三维角点及其不确定度；
2. 规范角点表征；
3. action chunk；
4. 最后才是未经解释的全部中间特征。

按角点可见性分层报告学生结果。若教师提升只发生在部署相机完全看不到角点的条件，不能声称这些信息可以无损压缩到单视角。

## 8. 决策规则

| 结果 | 下一步 |
|---|---|
| Mix-1 与最佳单视角/Single-repeat 接近 | 停止视角混合扩展，回查反馈、控制和接触 |
| Mix-1 在多个外部视角下稳定提升 | 进入 Random-2 和 All-3 |
| Random-2 或 All-3 进一步提升 | 开始深度、遮挡和相机依赖机制实验 |
| M3 不优于 M2 | 停止宣传跨视角 loss，保留负结果 |
| 教师强、学生在可见条件仍弱 | 检查蒸馏目标和单视角表示容量 |
| 教师只在完全遮挡时强 | 承认单视角不可观测边界，考虑保留多相机部署 |

## 9. Attention 的使用边界

可以记录每个阶段的相机 attention 或 gating 权重，但它们只作为诊断线索。任何“模型依赖某相机”的结论都必须用相机 mask、错帧替换或局部遮挡等干预验证，并报告对应的角点误差和成功率变化。
